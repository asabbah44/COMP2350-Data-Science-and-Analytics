# COMP2350 Final Project

Use `notebooks/Week15_Project_Template.ipynb` as the starting point.

## Required components

1. Clear problem formulation and stakeholder context.
2. Dataset provenance, license, observational unit, and data dictionary.
3. Reproducible data-quality audit and cleaning decisions.
4. Exploratory analysis with readable, relevant visualizations.
5. A justified inference, prediction, clustering, or association method.
6. Evaluation aligned with the problem and a leakage-free workflow.
7. Evidence-based findings, uncertainty, ethics, and limitations.
8. Citations and a notebook that runs from a fresh kernel.

## Submission

- Submit the completed notebook and any permitted supporting files.
- Use relative paths; do not submit absolute paths from your computer.
- Do not include secrets, personal identifiers, or restricted datasets.
- Keep raw data unchanged and document all transformations in code.
